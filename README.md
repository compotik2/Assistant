# Self-evolving Telegram бот для групп

Бота можно добавить в группу, и он **сам пишет себе новый код**, когда его просят
`научись ...`. Код сохраняется в `skills/*.py` и подхватывается без перезапуска.

## Как запустить (Windows)

1. Получи токен у [@BotFather](https://t.me/BotFather) → `/newbot`
2. Узнай свой ID у [@userinfobot](https://t.me/userinfobot)
3. Возьми `folderId` в [Yandex Cloud Console](https://console.yandex.cloud/folders)
   (твой API-ключ `AQ.Ab8...` уже вставлен в пример)
4. В папке бота:
```bat
copy .env.example .env
notepad .env
```
Впиши `BOT_TOKEN`, `OWNER_IDS`, `YANDEX_FOLDER_ID`
5. Запуск:
```bat
run.bat
```
или
```bat
pip install -r requirements.txt
python bot.py
```

## Как добавить в группу

1. В `@BotFather`: `/setprivacy` → выбери бота → `Disable`
   (иначе в группах он не будет видеть обычные сообщения)
2. Добавь бота в группу как участника, лучше сделай админом если нужно закреплять/удалять.
3. В группе напиши (от имени админа):
```
научись распределять сообщения
/skills
/code distribute
```

## Примеры фраз

- `научись распределять сообщения по темам: мемы, вопросы, новости`
- `/learn отвечай на слово спасибо фразой пожалуйста`
- `/learn считай кто чаще пишет`
- `/forget distribute`

## Безопасность (важно!)

Самомодифицирующийся код = выполнение чужого кода. Поэтому:

- Учить бота могут **только владелец (OWNER_IDS) и админы чата**.
- Перед сохранением код проверяется `safe_check()`:
  запрет `os.system`, `subprocess`, `socket`, `while`, левых импортов, токенов.
- Не давай OWNER права всем. Не выкладывай `.env` в интернет.
- Все навыки лежат открыто в `skills/*.py` — проверяй `/code имя` после обучения.

Без `YANDEX_FOLDER_ID` бот работает в режиме шаблона (простой keyword-роутер),
с ключом — генерирует умный код через YandexGPT.
